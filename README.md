# 🍦 Gellato - Site para Sorveteria (Projeto de Teste)

## 📝 Sobre o Projeto
O **Gellato** é um projeto de estudo e teste prático, desenvolvido com o objetivo de criar um site/e-commerce para uma sorveteria. 

A ideia principal foi colocar em prática a construção de um sistema web do zero, englobando desde a interface visual até a lógica de back-end e manipulação de banco de dados, simulando um ambiente real de desenvolvimento.

## 🛠️ Ferramentas e Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:

* **PHP**: Utilizado para toda a lógica de back-end, rotas e integração com o banco de dados.
* **MySQL**: Banco de dados relacional para armazenar informações de produtos, clientes, categorias e pedidos.
* **HTML5**: Estruturação das páginas web.
* **CSS3**: Estilização e design responsivo da interface (`style.css`).
* **JavaScript**: Utilizado para interações dinâmicas no front-end, como a lógica do carrinho de compras e validações de login.
* **XAMPP**: Ambiente de desenvolvimento local (Apache + MySQL) para rodar a aplicação.
* **Git e GitHub**: Para controle de versionamento do código.

## ⚙️ Funcionalidades Implementadas
O sistema conta com as operações básicas de um e-commerce (CRUD) e gerenciamento de usuários:

* **Autenticação**: Sistema de login, cadastro e logout de usuários.
* **Dashboard**: Painel de controle administrativo.
* **Gestão de Produtos**: Cadastrar, listar, editar e excluir os sorvetes/produtos.
* **Gestão de Categorias**: Organização dos produtos por categorias.
* **Gestão de Clientes**: Cadastro e listagem de clientes.
* **Carrinho de Compras**: Adição de itens e visualização do carrinho.
* **Pedidos**: Finalização e registro de pedidos.

## 🚀 Como rodar o projeto localmente

1. Instale o **XAMPP** em sua máquina.
2. Clone este repositório para dentro da pasta `htdocs` do seu XAMPP:
   ```bash
   git clone https://github.com/SEU-USUARIO/gellato.git
3. Abra o painel do XAMPP e inicie os serviços Apache e MySQL.

4. Importe o arquivo do banco de dados (caso exista um .sql no projeto) através do phpMyAdmin (http://localhost/phpmyadmin).

5. Acesse o projeto no navegador: http://localhost/gellato.
